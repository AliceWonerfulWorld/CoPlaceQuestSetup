# CoPlace：参加者向け課題説明文（2026-11-24）

この文書は両方式の共通説明・読み上げ用です。UIと同じ課題・評価基準を使用します。

## 新入生歓迎イベントを企画しよう

あなたたちは、大学のサークルの新入生歓迎イベントを企画するメンバーです。

各イベント候補について、新入生歓迎イベントとしてどの程度適しているかを考え、A〜Eの5段階に分類してください。

### 判断する際の参考

- 新入生が参加しやすいか
- 参加者同士が交流しやすいか
- 楽しめるイベントか

これらは判断の参考となる観点です。どの観点を重視するかは、自分の考えに基づいて判断してください。

この課題に正解はありません。

最終的には、参加者全員が同意できる分類結果を作成してください。

### A〜Eの評価基準

| Tier | 意味 |
|---|---|
| A | 非常に適している |
| B | やや適している |
| C | どちらともいえない |
| D | あまり適していない |
| E | まったく適していない |

未分類は、まだ分類されていない状態です。Cとは異なります。

すべての候補をA〜Eに分類します。同じTierに複数枚を配置でき、枚数制限はありません。すべてのTierを使う必要はなく、カード間の厳密な順位付けは不要です。未分類への移動や再分類もできます。

## 方式別の手順（適用済み方式だけを説明）

### 通常方式

1. イベント候補を確認する。
2. 参加者同士で話し合う。
3. すべてのイベント候補を共同でA〜Eに分類する。
4. 最終的な分類結果に全員が同意する。

共同分類中：参加者同士で話し合い、新入生歓迎イベントとしての適切さを評価してください。

### 提案方式

1. 各自の考えに基づいてイベント候補を分類する。
2. 独立回答を提出する。
3. 全員の独立回答が公開される。
4. 公開された回答も参照しながら話し合い、共同で分類する。
5. 最終的な分類結果に全員が同意する。

独立回答中：新入生歓迎イベントとしての適切さを、自分の考えに基づいて評価してください。

共同分類中：参加者同士で話し合い、新入生歓迎イベントとしての適切さを評価してください。

公開後は「独立回答を表示／閉じる」で参照パネルを開閉できます。

## 基本操作と終了

カードをつかみ、分類先で離してください。全員が最終的な配置に同意すると分類結果が確定します。

分類作業が終了したら、実験者からの次の案内をお待ちください。
